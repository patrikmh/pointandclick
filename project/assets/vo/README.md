# Röstklipp

Släpp de genererade MP3-filerna här. Filnamnen måste matcha `VOICE_SCRIPT.md` exakt —
koden bygger sökvägen som `assets/vo/<id>.mp3`.

Ett klipp som saknas failar tyst: repliken visas som text och munnen står stilla.
Spelet är alltså fullt spelbart medan inläsningen pågår, och varje inlagd fil
börjar höras direkt utan kodändring.

Undantag som INTE ligger här (ljudeffekter, inte röst): `assets/cave-ambience.mp3`.
